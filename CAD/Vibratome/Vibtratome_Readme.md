# Vibratome CAD

These parts are mostly optional. 
The dovetail clamp is just a minor upgrade to the existing VT1000 clamp.
It ensures the blade is always held at the same angle. 


The bushing is an upgrade to the ThorLabs right angle bracket. 
It makes changing the angle easier. 
The angle change can also be achieved without this modification, but it's slightkly trickier.
