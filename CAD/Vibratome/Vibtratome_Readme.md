# Vibratome CAD

## Bushing
The bushing is an upgrade to the ThorLabs right angle bracket. 
It makes changing the angle easier. 
The angle change can also be achieved without this modification, but it's somewhat trickier.
The bushing upgrade is definitely worth it. 

## Leica blade holder mod
The dovetail clamp is just a minor upgrade to the existing VT1000 clamp.
It ensures the blade is always held at the same angle and you don't need to push down on the holder when tightening the screw. 
This update is nice but very much optional. It's also a little tricky to install.
